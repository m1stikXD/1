# Dota Granny — мод для Minecraft Forge 1.20.1

Кроссовер: злая бабка-монстр + предметы в духе MOBA.

## Что внутри

| Что | Как работает |
|---|---|
| **Злая бабка** | Быстрый моб (40 HP), спавнится в Верхнем мире, бьёт и замедляет. Яйцо призыва в креативе. |
| **Золотая монета** | Выпадает из бабки (3–8 шт.). Нужна для крафта. |
| **Блинк-кинжал** | ПКМ — рывок вперёд до 14 блоков, перезарядка 8 сек. |
| **Мясной крюк** | ПКМ — бросает крюк и подтягивает первое существо на линии прицела (4 урона). |
| **Целебная мазь** | Выпить — мощная регенерация 10 сек. Иногда выпадает из бабки. |
| **Эгида бессмертия** | Лежит в инвентаре — один раз спасает от смерти. |

### Крафты

- Блинк-кинжал: `GEG / GSG` (G — золотая монета, E — жемчуг Края, S — палка)
- Крюк: `II / IS / _S` (I — железо, S — палка)
- Мазь: бутылка + золотая монета + сладкие ягоды (без формы)
- Эгида: тотем бессмертия в центре, вокруг 8 золотых монет

В креативе все предметы лежат во вкладке **Dota Granny**.

## Установка (если у тебя уже есть jar)

1. Установи Minecraft **1.20.1** и **Forge 47.3.0** (или новее для 1.20.1).
2. Положи `dotagranny-1.0.0.jar` в папку `mods`.
3. Запусти игру.

## Как получить jar

Нужны **JDK 17** и **Gradle 8.x** (8.8 проверенно подходит для ForgeGradle 6).

```
cd dotagranny
gradle build
```

Готовый файл появится в `build/libs/dotagranny-1.0.0.jar`.

Если ставить ничего не хочется: залей папку в свой репозиторий на GitHub — workflow
`.github/workflows/build.yml` соберёт jar сам (вкладка Actions → Artifacts).

## Текстуры

Все текстуры — простые заготовки (pixel art 16×16, скин моба 64×64).
Заменяй файлы в `src/main/resources/assets/dotagranny/textures/` на свои.
